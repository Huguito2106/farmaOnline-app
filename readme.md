Farmacia Online HUGO´s - Aplicación Web con Flask y SQLite

Descripción.
Este proyecto es una aplicación web desarrollada con Python (Flask) y SQLite para la gestión de una farmacia.  
Permite administrar medicamentos, clientes, proveedores y ventas mediante un CRUD básico y una interfaz sencilla en HTML.

Funcionalidades
-Medicamentos: listar, agregar y eliminar registros.
-Clientes: muestra lista de clientes.
-Proveedores: muestra lista de proveedores.
-Ventas: muestra ventas registradas.
-Interfaz web con tablas y formularios simples.
